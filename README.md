# Portfólio Bootstrap — Elton

Atividade de **Engenharia de Software**: página web responsiva com **Bootstrap 5**, HTML5 semântico e JavaScript nativo.

## Estrutura

```
index.html      Página principal (textos e componentes)
css/style.css   Ajustes mínimos de estilo
js/main.js      Validação do formulário e menu mobile
img/            Imagens dos projetos em destaque
```

## Como abrir

- **Local:** abra `index.html` no navegador (duplo clique).
- **GitHub Codespaces (recomendado pela disciplina):**
  1. Neste repositório: **Code** → **Codespaces** → **Create codespace on main**.
  2. Instale a extensão **Portuguese (Brazil) Language Pack** se quiser a interface em pt-BR.
  3. Use **Live Preview** ou abra `index.html` com um servidor simples (`python -m http.server`).

## Componentes

Navbar, carrossel, cards, tabela responsiva, formulário com validação e modal.

## Dependências

Apenas [Bootstrap 5.3.8](https://getbootstrap.com/) via CDN (CSS + bundle JS com Popper).
